Easy Fit – Use Case Catalogue

Each use case formatted in a structured table style inspired by provided reference. UC-XXX maps directly to REQ-XXX for traceability.

Use Case 1 (UC-001) – Client Account Registration & Login

Related RequirementREQ-001
Initiating ActorClient
Actor's GoalCreate verified client account and log in
Participating ActorsSystem, Email Service
PreconditionsUser not logged in; registration page reachable
PostconditionsVerified account active; session started
Flow of Events – Main Success Scenario
→1Client opens registration form
←2Enters details & submits
←3System validates; creates inactive account; sends verification email
←4Client clicks verification link
←5System activates account; logs client in; shows dashboard
Flow of Events – Extensions / Alternate
→AInvalid data: system shows field errors for correction
←BEmail delay/bounce: client requests resend; new token issued
←CExpired token: system issues fresh verification link
